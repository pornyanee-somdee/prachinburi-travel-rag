
# 🗺️ Prachinburi Travel RAG

Web Application RAG Chatbot สำหรับช่วยตอบคำถามเกี่ยวกับการท่องเที่ยวจังหวัดปราจีนบุรี

## 📌 หัวข้อโครงงาน

**Prachinburi Travel RAG — ผู้ช่วยท่องเที่ยวจังหวัดปราจีนบุรี**

ระบบสามารถตอบคำถามเกี่ยวกับ

- สถานที่ท่องเที่ยว
- แหล่งท่องเที่ยวทางธรรมชาติ
- ประวัติศาสตร์และวัฒนธรรม
- การเดินทาง
- อาหาร
- ผลิตภัณฑ์ท้องถิ่น
- กิจกรรมท่องเที่ยว
- ข้อมูลทั่วไปของจังหวัดปราจีนบุรี

โดยใช้แนวคิด **Retrieval-Augmented Generation (RAG)**
